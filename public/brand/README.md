# Assets de marca

Rutas canónicas (Master Prompt v2 §9). El componente `<Logo>` detecta estos archivos automáticamente:

- `logo.svg` — imagotipo completo, fondo claro
- `logo-dark.svg` — imagotipo para fondo morado oscuro
- `isotipo.svg` — solo la ficha con la "n"
- `_ref/logo.png` — referencia rasterizada; NO se sirve en el sitio

Mientras no exista el SVG oficial, `<Logo>` muestra un marcador tipográfico. No recrear el logo en código.
